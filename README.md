# Keo Sopharanith — Portfolio

Personal portfolio for Full Stack Development + Cybersecurity.

## Included
- Red spider lily image used as the personal logo and decorative visual identity.
- Light/dark theme with matching decorative animation and readable contrast.
- Responsive layouts for desktop, tablet and mobile.

- **Dental Clinic System:** HTML, CSS and JavaScript (the repository contains `index.html` and `style.css`, with JavaScript behavior in the HTML).
